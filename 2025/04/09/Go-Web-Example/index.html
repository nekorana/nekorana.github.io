HTTP服务器

一个HTTP服务器应当具备以下功能：

  1. 处理动态请求：处理浏览网站，登录账户，上传图像等用户传入的请求
  2. 提供静态资产：向浏览器提供JavaScript，CSS和图像，为用户创建动态体验
  3. 接受连接：服务器必须监听特定端口才能接受来自互联网的连接

net/http 包包含接收请求并动态处理它们所需的所有工具。我们可以使用 http.HandleFunc 函数注册一个新的处理程序。它的第一个参数接受一个要匹配的路径，第二个参数接受一个要执行的函数。

在处理动态请求方面， http.Request 包含有关请求及其参数的所有信息。我们可以使用 r.URL.Query().Get("token") 读取 GET 参数，或使用 r.FormValue("email") 读取 POST 参数（来自 HTML 表单的字段）。

使用mux首先需要创建一个新的请求路由器，该路由器作为web应用的主路由器，稍后将作为参数传递给服务器。它将接收所有 HTTP 连接，并将其传递给将在其上注册的请求处理程序。

模板

Go 的 html/template 包为 HTML 模板提供了丰富的模板语言。它主要用于 Web 应用程序中，以结构化的方式在客户端浏览器中显示数据。Go 模板语言的一大优势是数据自动转义。无需担心 XSS 攻击，因为 Go 会在将 HTML 模板显示给浏览器之前解析并转义所有输入。

用 Go 编写模板非常简单。本示例展示了一个待办事项列表，用 HTML 语言编写为无序列表 (ul)。渲染模板时，传入的数据可以是任何类型的 Go 数据结构。它可以是一个简单的字符串或数字，甚至可以是嵌套的数据结构，如下例所示。要访问模板中的数据，最顶层的变量可以通过 {{.}} 访问。花括号内的点称为管道，也是数据的根元素。

下面是模板的语法解释：

Control Structure Definition
{{/* a comment */}} 定义一个注释
{{.}} 渲染根元素
{{.Title}} 在嵌套元素中渲染“标题”字段
{{if .Done}} {{else}} {{end}} 定义一个条件控制语句
{{range .Todos}} {{.}} {{end}} 循环遍历所有“Todos”并使用 {{.}} 渲染每个表项
{{block "content" .}} {{end}} 定义一个名为“content”的块

模板可以从字符串或磁盘上的文件解析。通常情况下，模板是从磁盘解析的

模板从磁盘解析完成后，即可在 Execute 处理程序中使用。Execute 函数接受一个 io.Writer 参数用于写出模板，以及一个 interface{} 用于将数据传入模板。当在 http.ResponseWriter 上调用该函数时，HTTP 响应中的 Content-Type 标头会自动设置为 Content-Type: text/html; charset=utf-8 。

此示例将展示如何使用 Go 中流行的 gorilla/sessions 包将数据存储在会话 cookie 中。

Cookie 是存储在用户浏览器中的小块数据，每次用户请求时都会发送到我们的服务器。例如，我们可以在其中存储用户是否登录我们的网站，并识别用户（在我们的系统中）的身份。

在此示例中，我们仅允许经过身份验证的用户在 /secret 页面上查看我们的秘密消息。要访问该页面，用户首先必须访问 /login 以获取有效的会话 cookie，以便登录。此外，用户还可以访问 /logout 来撤销对秘密消息的访问权限。
