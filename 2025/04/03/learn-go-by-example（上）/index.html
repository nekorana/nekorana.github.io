learn go by example（上）

语言基础

Hello World

通过go run命令运行go语言程序，go build命令将go语言代码编译为可执行文件

Values

Go语言值类型包括字符串，整数，浮点数，布尔值等

Variables

在Go语言中， 变量由编译器明确声明和使用

Constants

Go语言各种类型均支持常量值，通过const关键字定义

For

Go语言中循环结构只有for一个关键字

If/Else

在 Go 中，条件不需要用括号括起来，但需要用大括号。

switch

  • 可以使用逗号分隔同一 case 语句中的多个表达式
  • 没有表达式的 switch 是另一种方法 表达 if/else 逻辑
  • 类型 switch 比较的是类型而不是值，可以使用它来发现接口值的类型

Arrays

  • go语言中的数组是特定长度的元素的编号序列
  • 如果使用 : 指定索引，则其间的元素将被清零

Slices

  • 与数组不同，切片仅由其包含的元素（而不是元素数量）来定义类型。未初始化的切片等于 nil，长度为 0
  • 要创建长度不为零的切片，可以使用内置命令 make ；默认情况下，新切片的容量等于其长度；如果我们知道切片会提前增长，则可以将容量作为附加参数显式传递给 make
  • 内置的 append 会返回包含一个或多个新值的切片。
  • 切片也可以 copy
  • 切片支持“切片”运算符
  • 切片可以组成多维数据结构。与多维数组不同，内部切片的长度可以变化。
  • slices 包中包含许多有用的切片实用函数。

Maps

  • 使用make创建空map
  • 若访问的键不存在，则返回值类型对应的零值
  • 内置 len 在map上调用时将返回键/值对的数量
  • 内置 delete 功能可以从映射中删除键/值对
  • 使用内置的 clear 可以从映射中删除所有键/值对

Functions

有多个连续的相同类型的参数时，可以省略同类型参数的类型名称，直到声明类型的最后一个参数

Multiple Return Values

Go 内置了对多个返回值的支持。该特性在惯用 Go 语言中经常使用，例如从函数返回结果和错误值。

Variadic Functions

可变参数函数可以使用任意数量的尾随参数来调用。

如果切片中已经有多个参数，可以将它们像func(slice...) 这样应用到可变函数中

Closures

Go 支持匿名函数 ，可以形成闭包。当你想以内联方式定义函数而不为其命名时，匿名函数非常有用。

Recursion

Go语言支持递归函数，匿名函数也可以递归，但这需要在定义函数之前明确声明一个用 var 的变量来存储该函数。

Range over Built-in Types

range关键字迭代各种内置数据结构中的元素

进阶特性

Pointers

Go 支持指针，允许程序员传递对程序内的值和记录的引用。

Strings and Runes

Go 字符串是只读的字节片段。语言和标准库对字符串有特殊处理 - 将其作为 UTF-8 编码文本的容器。在其他语言中，字符串由“字符”组成。在 Go 中，字符的概念称为 rune - 它是表示 Unicode 代码点的整数。

  • Go语言中string等价于[]byte
  • 对字符串进行索引会生成每个索引处的原始字节值。
  • 单引号中的值是符文文字。我们可以直接将rune值与符文文字进行比较。

Structs

Go 的结构体是字段的类型集合。它们可用于将数据分组以形成记录。

  • 如果结构类型仅用于单个值，则我们不会 必须给它一个名字。该值可以有一个匿名 结构类型。
  • 以在初始化结构时命名字段，省略的字段将为零值
  • 可以将:=与结构指针一起使用 - 指针会自动取消引用

Methods

Go 支持在结构类型上定义的方法 。可以为指针或值接收器类型定义方法。Go 自动处理方法调用时值与指针之间的转换。程序员可能希望使用指针接收器类型来避免方法调用时的复制，或者允许方法改变接收结构

Interfaces

接口是方法签名的命名集合，在 Go 中实现接口，只需要实现接口里的所有方法即可

如果变量具有接口类型，那么我们可以调用指定接口中的方法。

Enums

Struct Embedding

Go 支持结构和接口的嵌套，以实现更无缝的类型组合

嵌入带有方法的结构可用于将接口实现赋予其他结构。

Generics

Go1.18版本开始支持泛型，关于泛型的详情参考这篇博客

Range over Iterators

Go语言从1.23开始支持迭代器，使用迭代器我们可以更好地遍历各种容器

Errors

在 Go 中，通过显式、单独的返回值传达错误是一种惯用做法

  • 按照惯例，错误是最后一个返回值，并且具有类型 error ，这是一个内置接口。
  • errors.New 使用给定的错误消息构造一个基本的 error 值。
  • nil 值表示没有错误
  • 标记错误是一个预先声明的变量，用于表示特定的错误情况。
  • 我们可以用更高级别的错误包装错误来添加 上下文。最简单的方法是使用 fmt.Errorf 中的 %w 动词。包装的错误会创建一个逻辑链（A 包装 B，B 包装 C）
  • errors.Is 检查给定错误（或其链中的任何错误）是否与特定错误值匹配。

Custom Errors

通过在自定义类型上实现 Error() 方法，可以将自定义类型用作 error 。

errors.As 是 errors.Is 的更高级版本。它检查给定的错误（或其链中的任何错误）是否与特定的错误类型匹配，并转换为该类型的值，返回 true 。如果不匹配，则返回 false 。
