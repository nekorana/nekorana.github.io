异步编程

Goroutines

go协程（goroutine）是一种轻量级的执行线程，通过go关键字启用，可以启动goroutine进行匿名函数调用

Channels

通道（channel）是连接并发goroutine的管道，goroutine可以将一个值发送到channel中，而另一个goroutine可以从channel中接收这个值，从而完成goroutine之间的通信

默认情况下，发送和接收会阻塞，直到发送方和接收方都准备好为止。此属性允许我们在程序结束时等待 "ping" 消息而无需使用任何其他同步。

Channel Buffering

默认情况下，通道是无缓冲的，这意味着，只有当有相应的接收方 ( <- chan ) 准备好接收发送的值时，它们才会接受发送 ( chan <- )。 缓冲通道接受有限数量的值，而这些值没有相应的接收器。

Channel Synchronization

我们可以使用通道来同步 goroutine 之间的执行。

Channel Directions

当使用通道作为函数参数时，可以指定通道是否仅用于发送或接收值。这种特异性提高了程序的类型安全性。

Select

Go 的select可以让程序等待多个通道操作。将goroutines和通道与 select 结合起来是 Go 的一个强大功能。

Timeouts

对于连接到外部资源或需要限制执行时间的程序来说， 超时非常重要。借助通道和 select ，在 Go 中实现超时既简单又优雅。

Non-Blocking Channel Operations

通道上的基本发送和接收都是阻塞的。但是，我们可以使用带有 default 子句的 select 来实现非阻塞的发送、接收，甚至非阻塞的多路 select 。

Closing Channel

关闭通道表示不再向其发送任何值，这对于向通道的接收者传达完成信息很有用。

从已关闭的通道读取数据会立即成功，并返回基础类型的零值。如果接收到的值是由成功发送到通道的操作传送的，则可选的第二个返回值为 true ；如果接收到的值是由于通道已关闭且为空而生成的零值，则返回值为 false 。

Range over Channels

我们还可以使用range语法迭代从通道接收的值

Timer

Go内置的计时器（Timer）可以帮助我们编写在某个时间间隔内重复执行的逻辑

<-timer.C会阻塞定时器的通道C，直到它发送一个指示计时器已触发的值。

Tickers

计时器适用于想要在未来做某事一次的情况 - Ticker适用于想要定期重复做某事的情况

Workers Pools

在Go中可以通过goroutine和通道实现工作池

WaitGroups

要等待多个 goroutine 完成，我们可以使用sync.WaitGroup。

  • WaitGroup.Add方法将WaitGroup的计数器加1
  • WaitGroup.Done方法将WaitGroup的计数器减1
  • WaitGroup.Wait方法将阻塞主协程直到WaitGroup的计数器减为0

Rate Limiting

Atomic Counters

Go语言中可以通过原子计数器（Atomic Counter）来进行状态管理

使用 Load ，即使其他 goroutine 正在（原子地）更新该值，也可以安全地原子地读取该值。

Mutexes

上面介绍了利用原子操作进行状态管理，对于一些更复杂的状态管理操作，可以利用互斥锁来完成

Stateful Goroutines

仅使用通道和goroutine也可以完成状态的管理

内置库与函数

Sorting

Go 的 slices 包实现了内置和用户定义类型的排序

Sorting by Functions

我们可以通过自定义比较函数，来进行自然顺序以外的其它顺序的排序

Panic

panic 通常意味着发生了意外错误。我们主要用它来快速处理在正常操作期间不应该发生的错误，或者我们没有准备好妥善处理的错误。

Defer

defer关键字可以推迟操作的执行，让指定操作在函数返回前才自动完成

Recover

Go 可以使用内置函数 recover 从 panic 中恢复 。recover 可以阻止 panic 中止程序，并且执行错误处理逻辑

  • 必须在延迟函数中调用 recover 。当封闭函数发生恐慌时，延迟函数将激活，并且其中的 recover 调用将捕获恐慌。
  • recover 的返回值是 panic 调用中引发的错误。

String Functions

标准库的 strings 包提供了很多有用的字符串相关函数。

String Formatting

Go的fmt.Printf等函数为字符串的格式化输出提供了强大的功能支持

Text Templates

Go 内置了创建动态内容或使用 text/template 包向用户显示自定义输出的支持。

Regular Expression

JSON

只有导出的字段才会以 JSON 格式进行编码/解码。字段必须以大写字母开头才能导出。

Time

Time Formatting / Parsing

Go 支持通过基于模式的布局进行时间格式化和解析。

Random Numbers
