两数之和

题干

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target 的那 两个 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

解答

初始化一个哈希表，在遍历数组的同时，在哈希表中寻找当前整数nums[i]的匹配对象another，找到则直接返回，找不到则将当前整数存入哈希表中，这样在遍历到another时就能在哈希表中找到匹配对象

三数之和

题干

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

解答

先将数组排序，再对数组进行遍历，利用双指针法，left指向当前整数的下一个数据，right指向最后一个数据，由数据的有序性可知，若此时三数之和小于0，则证明left应该右移一位，反之则right应该左移一位，若恰好等于0则将三个整数存入答案

盛最多水的容器

题干

给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

解答

核心在于需要理解：若使用相向双指针法，那么对于选定的左右两个边而言，面积大小是被较短的一边限制了（也就是说如果固定短边，改变长边，无论如何面积都会减小），所以每次都要移动指向短边的指针

接雨水

题干

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

解答

使用相向双指针法，当前格子的容量为前缀最大高度与后缀最大高度中较小的一方减去当前格子的高度（前缀最大高度较小则当前格子为左指针指向的格子，反正则为右指针），计算后移动指针

无重复字符的最长子串

题干

在一个字符串重寻找没有重复字母的最长子串。

解答

滑动窗口的右边界不断的右移，只要没有重复的字符，就持续向右扩大窗口边界。一旦出现了重复字符，就需要缩小左边界，直到重复的字符移出了左边界，然后继续移动滑动窗口的右边界。以此类推，每次移动需要计算当前长度，并判断是否需要更新最大长度，最终最大的值就是题目中的所求

在有序数组中查找元素第一个和最后一个的位置

题干

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 target，返回 [-1, -1]。

你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题。

解答

利用两个工具函数searchFirt和searchLast分别对第一个和最后一个位置进行二分查找，查找过程中需要对mid指针进行边界判断，同时由于可能会出现目标元素连续分布的情况，需要对mid的上/下一个元素进行判断

搜索旋转排序数组

题干

整数数组 nums 按升序排列，数组中的值 互不相同 。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 向左旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,5,6,7] 下标 3 上向左旋转后可能变为 [4,5,6,7,0,1,2] 。

给你 旋转后 的数组 nums 和一个整数 target ，如果 nums 中存在这个目标值 target ，则返回它的下标，否则返回 -1 。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

解答

原数组已经是严格递增的，向左旋转本质上是把数组切开成两部分，两个部分内部是有序的，且前半部分最小值（nums[left]）必定大于后半部分最大值（nums[right]），此时就可以通过判断nums[mid]与二者的大小关系来判断mid落入哪一个区间，例如：

  • 若nums[mid] > nums[left]：证明mid指向前半部分
  • 若nums[mid] < nums[left]：证明mid指向后半部分
